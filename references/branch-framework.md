# 人生分岔路 · 推演框架

本文件在推演前对照，确保结构完整、不偏离「推演而非预测」。

## 一、四个时间节点推演框架

每段都必须同时产出「收益 / 代价 / 不可控变量」三项，缺一项视为未完成。

| 节点 | 关注重点 | 写法要求 |
|---|---|---|
| 1 年 | 短期适应 | 写刚切换时的具体变化：住哪、收入、人际关系、日常节奏；代价侧重「落差与重新起步的累」 |
| 3 年 | 中期积累 | 写能力/资源/关系的累积或停滞；收益与代价都要落到具体事项（职位、存款、孤独感等） |
| 5 年 | 长期分野 | 写两条路开始明显分叉处；不写「人生赢家」，写「另一种稳定的状态与它的代价」 |
| 现在（那条路的你） | 回望 | 写「这条路的你此刻可能在意什么」，为结尾回到现实做铺垫 |

填写口径：
- 收益：基于当年可知道的信息，合理推断的 positives，用「大概率」「可能」。
- 代价：同口径的 negatives，必须写，不允许只渲染一面。
- 不可控：依赖运气或他人选择的结果（遇到谁、行业变化、对方反应），标为「不可控」，给区间不给定数。

## 二、常见的推演失真来源（必须规避）

1. **后见之明** — 用现在已知的结果倒推当年，让那条路显得理所当然。规避：只基于当年可知道的信息推演，不掺入事后才知道的事。
2. **把不可控当可控** — 把运气（遇到贵人、行业起飞）写成确定结果。规避：凡取决于他人或运气者标「不可控」，给多种可能。
3. **只写好不写坏（或只写坏不写好）** — 单方面渲染。规避：强制双侧，每段收益与代价并列。
4. **把他人反应理想化** — 按用户期望编「TA 一定支持你」。规避：他人反应一律标不可控，给多种可能。
5. **情绪替代推演** — 用户低落时把推演写成安慰或指责。规避：始终保持双侧与不可控标注，情绪化追问时转回现实可做的事。

## 三、边界提示触发条件

出现以下任一，必须在对应位置加一句提示咨询专业人士，不代下结论：
- 涉及重大医疗决策（手术、治疗选择）
- 涉及法律后果（诉讼、合同、婚姻）
- 涉及大额财务（买房、辞职无储蓄、投资本金占比过高）

提示语范式：「这块涉及 [医疗/法律/大额财务]，推演无法替代专业判断，建议咨询对应专业人士。」
